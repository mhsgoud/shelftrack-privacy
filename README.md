# ShelfTrack — Privacy policy (GitHub Pages)

Public repo for the ShelfTrack privacy policy only. The app source stays private.

**Live URL:** https://mhsgoud.github.io/shelftrack-privacy/privacy-policy.html

## Publish updates

1. Push to `main` (GitHub Actions deploys automatically).
2. In the repo: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

If the live page looks outdated, open **Actions**, run **Deploy privacy policy to GitHub Pages**, then hard-refresh the browser (Ctrl+Shift+R).
